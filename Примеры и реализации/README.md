# How to use

Каждая подпапка содержит свой `README.md`, в котором слинковано всё необходимое + краткое описание. Сборка кода вариируется от того, кто это дело коммитил.
`LeastDepressedDev` обычно оставляет `build.sh`, который собирает всё.
